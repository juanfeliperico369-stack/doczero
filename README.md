# Doc Element

Juego educativo arcade y offline de química real: forja elementos, construye moléculas y polímeros con bloques conectables, y resuelve los problemas del universo a bordo de la nave alquimista Ouroboros.

**One Zero por Infinite Tree.**

- Jugar: abre `index.html` en cualquier navegador. Funciona sin internet y en celular o PC.
- Compilar: `node tools/build.mjs` (une `src/` en `index.html`).
- Probar: `node tools/bot.mjs 100` (Playwright: UI móvil/PC, validación de datos, solver de los 100 problemas y 100 partidas aleatorias).
- Contexto completo para continuar el proyecto: [`docs/GUIA_IA.md`](docs/GUIA_IA.md) · Cambios: [`docs/BITACORA.md`](docs/BITACORA.md).
